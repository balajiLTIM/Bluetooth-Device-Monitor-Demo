# Bluetooth-Device-Monitor-Demo

A demo iOS application built to showcase:

- Clean Architecture
- MVVM
- Coordinator Pattern
- SOLID Principles
- Dependency Injection
- Repository Pattern
- SwiftUI
- Bluetooth Lifecycle Management
- Swift Concurrency
- Unit Testing
- Debugging & Profiling

## Features

### Dashboard
- Device statistics
- Connection overview

### Device Management
- Device list
- Device detail screen

### Bluetooth Simulation
- Scan
- Connect
- Disconnect
- Reconnect

### Debugging Lab
- Memory leak examples
- Retain cycle examples
- Performance examples
